Buying tickets on Events Manager is a straightforward process: you pick the ticket type and quantity you want, fill in your attendee details, and then complete payment via a secure PIX checkout hosted by AbacatePay. Your unique ticket code is generated as soon as your payment is confirmed. The entire flow takes just a few minutes and requires no credit card.

<Warning>
  You must be logged in to an Events Manager account to purchase tickets. If you haven't registered yet, create a free account before proceeding to checkout.
</Warning>

## Purchase flow

<Steps>
  <Step title="Open the event page">
    Navigate to `/eventos` and click on the event you want to attend, or use the direct URL `/eventos/{event-slug}`.
  </Step>
  <Step title="Select your ticket">
    On the event detail page, scroll to the **Ingressos** section. Each ticket type shows its name, description, price (including any convenience fee), and a live availability bar. Click **Selecionar** next to the ticket type you want, or use the **Comprar ingressos** button in the sidebar to proceed to the checkout page.
  </Step>
  <Step title="Choose quantity">
    On the checkout page (`/eventos/{slug}/checkout`), select the number of tickets. Organisers may set a minimum and maximum quantity per purchase — you'll be informed if you exceed those limits.
  </Step>
  <Step title="Enter attendee information">
    Fill in the participant details form. The following fields are collected:

    | Field        | Required | Notes                                  |
    |--------------|----------|----------------------------------------|
    | `name`       | ✅ Yes   | Full name of the attendee              |
    | `email`      | ✅ Yes   | Confirmation and ticket delivery       |
    | `phone`      | No       | Optional contact number                |
    | `document`   | No       | CPF or other ID document               |
  </Step>
  <Step title="Choose payment method">
    Select **PIX** as your payment method. If the ticket has installments enabled, you can also choose **PIX Parcelado** — see the [PIX Installments](/attendees/pix-installments) guide for details. The full amount (or first installment) is displayed before you confirm.
  </Step>
  <Step title="Complete payment on AbacatePay">
    You are redirected to a hosted AbacatePay checkout page. Scan the PIX QR code with your bank's app, or copy and paste the PIX code ("Pix copia e cola") into your banking app. The payment must be completed within the session window shown on screen.
  </Step>
  <Step title="Receive your ticket code">
    After payment is confirmed, you are redirected to the `/eventos/{slug}/checkout/success` page showing your registration. Your unique `ticket_code` is emailed to you and also visible in [My Tickets](/attendees/my-tickets) (`/meus-ingressos`).
  </Step>
</Steps>

## Checkout request schema

When the frontend submits your order it sends the following payload to `POST /api/payments/checkout`:

```json title="Checkout request body"
{
  "eventId": "uuid-of-the-event",
  "tickets": [
    {
      "ticketId": "uuid-of-the-ticket-type",
      "quantity": 2
    }
  ],
  "participantInfo": {
    "name": "Maria Silva",
    "email": "maria@example.com",
    "phone": "+5511999990000",
    "document": "123.456.789-00"
  }
}
```

| Field                        | Type    | Required | Description                                   |
|------------------------------|---------|----------|-----------------------------------------------|
| `eventId`                    | UUID    | ✅       | The event you are registering for             |
| `tickets`                    | array   | ✅       | At least one ticket entry is required          |
| `tickets[].ticketId`         | UUID    | ✅       | The specific ticket type                      |
| `tickets[].quantity`         | integer | ✅       | Must be a positive integer                    |
| `participantInfo.name`       | string  | ✅       | Cannot be blank                               |
| `participantInfo.email`      | string  | ✅       | Must be a valid email address                 |
| `participantInfo.phone`      | string  | No       | Optional phone number                         |
| `participantInfo.document`   | string  | No       | Optional CPF or document number               |

## Payment methods

Events Manager supports the following payment methods, depending on the ticket configuration:

<CardGroup cols={2}>
  <Card title="PIX" icon="bolt">
    Instant payment via the Brazilian PIX system. The QR code and copy-paste code are generated by AbacatePay and expire after a short window.
  </Card>
  <Card title="PIX Installments" icon="calendar">
    Split your purchase into 2–12 monthly PIX charges. Only available on tickets with `allow_installments = true`. See the [PIX Installments](/attendees/pix-installments) guide.
  </Card>
  <Card title="Card" icon="credit-card">
    Credit or debit card payment processed via AbacatePay. Availability depends on organizer settings.
  </Card>
  <Card title="Free" icon="gift">
    No payment required. Used for events or tickets with a price of R$ 0.00. Registration is confirmed immediately.
  </Card>
</CardGroup>

## Registration statuses

After your checkout is submitted, your registration moves through the following statuses:

| Status            | Meaning                                                                              |
|-------------------|--------------------------------------------------------------------------------------|
| `pending`         | Checkout created; waiting for your PIX payment to be confirmed.                      |
| `confirmed`       | Payment received and verified. Your ticket code is active.                           |
| `partial_payment` | An installment plan is active and at least one installment has been paid.            |
| `payment_overdue` | One or more installments are past their due date.                                    |
| `cancelled`       | The registration was cancelled (e.g. payment was never completed and the session expired). |
| `checked_in`      | You have been checked in at the event venue.                                         |

<Note>
  The system automatically reconciles pending checkouts against the payment gateway on a periodic schedule. If your status does not update within a few minutes after paying, visit [My Tickets](/attendees/my-tickets) and use the status refresh option, or contact the event organizer.
</Note>

<Accordion title="What happens if I close the browser before finishing payment?">
  Your checkout session is saved. You can return to the event page and start a new checkout. Uncompleted sessions are automatically reconciled and cleaned up by the platform after a grace period. If your PIX payment went through but your registration still shows `pending`, wait a few minutes for automatic reconciliation to update the status, or check [My Tickets](/attendees/my-tickets).
</Accordion>

<Accordion title="Can I buy tickets for someone else?">
  Yes. The `participantInfo` fields (name, email, phone, document) represent the attendee — you can enter another person's details. The ticket code will be sent to the email address you provide in that form.
</Accordion>
